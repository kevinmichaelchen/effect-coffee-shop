# Foldkit UI

Use the official Foldkit skills and examples matching the pinned package version.
Keep Model and Message schema-defined, update and view pure, effects in named
Commands, and live feeds in scoped Subscriptions. Use @foldkit/ui for controls.
Decode external input at boundaries and keep identity out of client authority.
Keep light/dark themes, accessible labels, keyboard focus, and narrow layouts.
Run `bun run --cwd apps/ui check` after changes.
